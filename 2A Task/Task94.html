Open Graph Social Preview

Open Graph meta tags help social media platforms understand how your website should appear when someone shares its URL.

T

og:title

Defines the title that appears in the social media preview.

D

og:description

Provides a short description of the shared webpage.

I

og:image

Defines the image displayed in the social media preview.

U

og:url

Specifies the canonical URL of the webpage.

W

og:type

Defines the type of content, such as website or article.

S

og:site_name

Defines the name of the website or brand.
