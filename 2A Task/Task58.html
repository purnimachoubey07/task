HTML stands for HyperText Markup Language. It is used to create the structure of web pages using different elements and tags.

CSS stands for Cascading Style Sheets. It is used to design and style HTML elements, including colors, spacing, fonts and layouts.

JavaScript is a programming language used to make web pages interactive and dynamic. It can handle events, manipulate the DOM and update webpage content.

DOM stands for Document Object Model. It represents an HTML document as a tree of objects that JavaScript can access and modify.

JavaScript is used to add interactivity to websites, such as forms, menus, sliders, modals, tabs, accordions and dynamic content.
